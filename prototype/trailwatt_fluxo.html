Seu treino ja diz o percurso ideal.

Digite o alvo do treino de hoje e o Trailwatt sugere uma rota real que bate com ele — calculado no seu aparelho, sincronizado com a nuvem, pronto para exportar para o Strava, Garmin ou Wahoo.

Comecar gratis Ver como funciona

iPhone e Android  ·  processamento local  ·  dados na AWS

Alvo por potencia ou FC

Do FTP de 150w ao de 300w, o motor calcula o gradiente certo para o seu nivel — a mesma logica serve para quem treina por frequencia cardiaca.

Calculo 100% local

O motor fisico roda no proprio aparelho. Funciona mesmo sem internet — a nuvem so entra depois, para guardar o que ja foi calculado.

Exporta e importa sozinho

Manda a rota pronta para o Strava, Garmin ou Wahoo, e busca o resultado de volta pela API assim que o treino termina.
